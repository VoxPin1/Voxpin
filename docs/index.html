1. Restore Apps Script (Docs notes)

In Google Apps Script → Deploy → Manage deployments → copy the Web app URL (.../macros/s/.../exec). Use the same secret as in your script’s SECRET constant. Doc id in the example is already set in the app.

2. OAuth for Calendar

Required for reminders and next-event on the pin (separate from Apps Script). Create a Desktop OAuth client in Google Cloud, paste the JSON, Save, then Sign in.
