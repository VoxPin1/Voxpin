Sign in

Sign in with Google, then load notes from your Google Doc (Drive) and events from Calendar. The site only displays that data — Google stores it. You do not need a VoxPin server for this. A server is only needed if the pin should upload while this page is closed (Apps Script can do that into the same Doc).

Sign in with Google

In Google Cloud → APIs & Services → Credentials, create an OAuth client of type Web application. Add these Authorized JavaScript origins: https://voxpin1.github.io and http://127.0.0.1:8765. Then paste the Client ID below. Also enable the Google Calendar API and Google Docs API on that Cloud project.

This computer only — Apps Script (Docs notes)

In Google Apps Script → Deploy → Manage deployments → copy the Web app URL (.../macros/s/.../exec). Use the same secret as in your script’s SECRET constant. Doc id in the example is already set in the app.

This computer only — Desktop OAuth for the pin

Needed so the pin can write reminders while this website is closed. Create a Desktop OAuth client, paste the JSON, Save, then Sign in. This is separate from Sign in with Google above.
